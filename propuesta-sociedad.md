# Propuesta de Sociedad Tecnológica — Magastore Backoffice

**Fecha:** Junio 2026  
**Partes:** Farid Villacis (desarrollador) & Socio Magastore  

---

## 1. Contexto

Magastore opera como servicio de courier entre Miami y Costa Rica. Para escalar sus operaciones, se desarrolló un sistema de backoffice a medida que hoy es el núcleo operativo del negocio.

Este documento formaliza el valor de ese sistema y establece una propuesta de participación justa para ambas partes.

---

## 2. El Sistema — ¿Qué se construyó?

El sistema cubre de extremo a extremo la operación de Magastore:

| Módulo | Funcionalidad | Complejidad | Valor asignado |
|---|---|---|---|
| **Autenticación y seguridad** | Login seguro con JWT, control de acceso por rol | Alta | $50 |
| **Clientes + importación masiva** | Registro, edición, importación masiva, gestión de direcciones | Alta | $100 |
| **Paquetes / Logística** | Registro de entrada, estados de tránsito, notas internas, evidencia fotográfica | Muy alta | $130 |
| **Facturación automática** | Cálculo automático por peso, tipo de cambio y tarifas configurables | Alta | $90 |
| **Consolidaciones** | Agrupación de paquetes por cliente y despacho | Media-alta | $70 |
| **Configuración + auditoría** | Tarifas del sistema con historial completo de cambios | Media | $50 |
| **Tracking público** | Portal para que clientes consulten sus paquetes | Media | $55 |
| **Dashboard operativo** | Métricas operativas en tiempo real | Media | $55 |
| | | **Total** | **$600 USD** |

Stack tecnológico: Next.js 14, TypeScript, PostgreSQL (Neon), React Query, Tailwind CSS.

## 3. Valor de Mercado del Sistema

Si Magastore hubiera contratado este desarrollo en el mercado libre:

| Modalidad | Costo estimado |
|---|---|
| Freelance (mercado latinoamericano) | $3,000 — $6,000 USD |
| Agencia de software en Costa Rica | $5,000 — $12,000 USD |
| SaaS equivalente (suscripción mensual, sin personalización) | $80 — $200 USD/mes indefinidamente |
| Licencia de código fuente one-time | $2,500 — $5,000 USD |

**El sistema fue entregado sin costo hasta la fecha.** Esta propuesta busca reconocer ese aporte de forma razonable y sostenible para ambas partes.

## 5. Propuesta de Participación

### Pago inicial (reconocimiento por lo ya entregado)

| Concepto | Monto |
|---|---|
| Reconocimiento por desarrollo del sistema base | **$600 USD** |
| Forma de pago | Acordar entre las partes (único o en cuotas) |

Este monto no representa el valor real del sistema — representa un gesto simbólico justo entre socios, lejos del precio de mercado.

### Participación mensual

| Porcentaje propuesto | Base de cálculo |
|---|---|
| **20% mensual** | Sobre utilidades netas de Magastore |

> **Utilidades netas** = ingresos totales menos gastos operativos directos (no incluye salarios ficticios ni gastos no documentados).

## 6. Proyección en Números

| Escenario | Ingreso mensual Magastore | Participación (20%) | Equivalente USD aprox. |
|---|---|---|---|
| Hoy (conservador) | 150,000 CRC | 30,000 CRC | ~$55 |
| Crecimiento moderado (6 meses) | 400,000 CRC | 80,000 CRC | ~$145 |
| Crecimiento real (12 meses) | 800,000 CRC | 160,000 CRC | ~$290 |
| Escala media (18–24 meses) | 1,500,000 CRC | 300,000 CRC | ~$545 |

El sistema es un activo directo que permite este crecimiento: sin él, la operación depende de procesos manuales que no escalan.

---

## 7. Condiciones Propuestas

1. **Participación mensual** pagada los primeros 5 días hábiles de cada mes.
2. **Transparencia de ingresos**: acceso mensual a un resumen de ingresos y gastos para calcular la base correctamente.
3. **Features nuevas**: se incluyen dentro del acuerdo hasta un máximo razonable (a definir). Desarrollos de gran escala se acuerdan por separado.
4. **Duración**: indefinida mientras el sistema esté en uso activo por Magastore.
5. **Salida**: cualquiera de las partes puede renegociar con 60 días de aviso previo.
6. **Propiedad del sistema**: el código fuente permanece en custodia del desarrollador hasta que exista un acuerdo de traspaso formal y compensado.

---

## 8. Por Qué Esto es Justo para Ambas Partes

**Para Magastore:**
- Pago inicial muy por debajo del costo de mercado ($600 vs $3,000–$6,000)
- Sin costo de licencia mensual fijo (como tendría un SaaS)
- La participación crece con el negocio — cuando no hay ganancias, no hay pago
- Sistema personalizado a la medida de la operación, no una solución genérica

**Para el desarrollador:**
- Reconocimiento justo por el tiempo y expertise invertidos
- Participación en el crecimiento que el propio sistema habilita
- Relación sostenible a largo plazo, no un pago único y fin
